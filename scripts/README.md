# PMOSense Automation & Helper Scripts

Utility scripts for database migrations, local seed data generation, ML dataset validation, and environment verification.

---

## 🛠️ Scripts Directory

- `seed_dev_data.py`: Populate local development database with sanitized mock longitudinal test data.
- `verify_env.py`: Verify all required system binaries (Python, Node, Tesseract) and environment variables are properly configured.
