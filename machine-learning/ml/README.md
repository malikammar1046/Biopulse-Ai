# OvaSense ML Intelligence Layer

## ⚠️ RESEARCH PROTOTYPE — SYNTHETIC TRAINING DATA — NOT CLINICALLY VALIDATED

This ML system is a research prototype trained on synthetic data. It has **not** been
clinically validated and is **not** a medical device.

---

## Overview

The ML intelligence layer provides:
1. **Feature Engineering** — 22 numeric features from patient health logs
2. **Data Quality Assessment** — determines if enough data exists for inference
3. **ML Inference** — RandomForestClassifier via sklearn Pipeline
4. **SHAP Explainability** — real TreeExplainer feature contributions
5. **Pattern Classification** — lower/moderate/higher metabolic health risk patterns

## Feature Definitions

| 11 | `hirsutism_frequency` | Days with hair growth concerns / total days |
| 12 | `average_water_intake_glasses` | Mean daily water glasses |
| 13 | `average_sleep_hours` | Sleep hours from profile |
| 14 | `average_daily_movement_mins` | Mean daily fitness minutes |
| 15 | `workout_frequency_per_week` | Workouts per week |
| 16 | `food_logging_frequency` | Days with food logs / total days |
| 17 | `medication_adherence_rate` | Taken / (taken + missed) |
| 18 | `active_prescription_count` | Number of active medications |

## Setup and Training

```bash
# Install dependencies
pip install -r ml/requirements.txt

# Train the model (from repo root)
python -m ml.training.train_pipeline
```

Training output:
- 900 synthetic samples (40% lower / 35% moderate / 25% higher)
- 5-fold cross-validation on balanced accuracy
- Artifacts saved to `ml/artifacts/`

---

## Inference

```python
from ml.inference.predictor import predictor
from ml.features.feature_extractor import extract_features
from ml.features.data_quality import calculate_data_quality

health_data = ...  # PatientHealthData from SupabaseHealthService
dq = calculate_data_quality(health_data)

if dq.quality_level != 'insufficient_data':
    features = extract_features(health_data, dq.date_span_days)
    result = predictor.predict(features)
    print(result.risk_pattern, result.probabilities)
```

## SHAP Explainability

```python
from ml.explainability.shap_explainer import shap_explainer

shap_explainer.load(predictor.classifier, predictor.feature_names)
explanations = shap_explainer.explain(
    feature_vector_imputed=result.feature_vector_imputed,
    predicted_class_idx=0,  # lower_pattern
    top_n=5
)
```

## Output Classes

| Class | Description |
|-------|-------------|
| `lower_pattern` | Lower metabolic health risk pattern |
| `moderate_pattern` | Moderate metabolic health risk pattern |
| `higher_pattern` | Higher metabolic health risk pattern |
| `insufficient_data` | Insufficient logged data for inference |

**Never produced**: "You have PCOS", "You have diabetes", or any medical diagnosis.
